# Проект "Smart Directory" (Автоматизированный корпоративный справочник)

## Статус компонентов системы:
- **Telegram Bot**: [ВНЕШНЯЯ СИСТЕМА]. Разрабатывается и хостится как отдельный проект. Выступает потребителем API (клиентом).
- **Backend/API (api_gateway)**: [К РАЗРАБОТКЕ]. Центральный узел системы, обслуживающий внешние интерфейсы.
- **Web Portal (Фронтенд)**: [К РАЗРАБОТКЕ]. Основной интерфейс самообслуживания (Gatekeeper и Админ-панели).
- **Active Directory (AD)**: [ИСТОЧНИК]. Мастер-система (SSOT). Контакты требуют актуализации.
- **AD Sync Worker**: [К РАЗРАБОТКЕ]. Изолированный микросервис для синхронизации с AD.

## Бизнес-цель:
Создать платформу управления корпоративными контактами, где AD является "Единым источником истины", но его обновление делегировано самим сотрудникам (через Web-портал) и контролируется алгоритмами валидации и ИТ-оператором.

## Инструкция по запуску

### Первый запуск (настройка окружения)
1.  **Подготовка переменных окружения:**
    Скопируйте файл примера настроек в локальный файл `.env`:
    ```bash
    cp .env.example .env
    ```
2.  **Конфигурация:**
    Отредактируйте файл `.env`, указав актуальные данные для подключения к Active Directory (LDAP), настройки базы данных и секретные ключи для JWT.
3.  **Сборка и запуск контейнеров:**
    Запустите систему с автоматической сборкой образов:
    ```bash
    docker compose up -d --build
    ```
    *База данных будет автоматически инициализирована скриптом `init.sql` при первом старте.*

### Повторный запуск
Для последующих запусков (если конфигурация и код не менялись) достаточно выполнить:
```bash
docker compose up -d
```

### Мониторинг и проверка
*   **Логи сервисов:** `docker compose logs -f`
*   **Web-интерфейс:** [http://localhost](http://localhost)
*   **API Gateway (Swagger):** [http://localhost:8000/docs](http://localhost:8000/docs)
*   **Проверка здоровья (Healthcheck):** `docker compose ps`
