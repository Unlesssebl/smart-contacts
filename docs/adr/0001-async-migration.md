# ADR 0001: Стратегия перехода на полностью асинхронный стек (Async Migration)

* **Статус:** Предложено / Запланировано (Proposed)
* **Дата:** 2026-07-05
* **Контекст:** Масштабирование FastAPI бэкенда при росте RPS и нагрузок на Active Directory / PostgreSQL.

---

## 1. Контекст и проблематика

В архитектуре системы выявлено потенциальное «бутылочное горлышко» при высоких нагрузках. Использование синхронных вызовов к базам данных и LDAP внутри асинхронного фреймворка FastAPI может приводить к исчерпанию пула потоков (**Threadpool Exhaustion**).

В текущей версии проблема решена маршрутизацией эндпоинтов через обычные синхронные функции (`def` вместо `async def`), что позволяет FastAPI автоматически выполнять их в пуле потоков (`anyio.to_thread`). Для текущих нагрузок этого достаточно.

### Факторы риска текущего решения при росте нагрузок:
1. **Потребление ресурсов:** Синхронные потоки операционной системы потребляют значительно больше памяти и CPU на переключение контекста по сравнению с корутинами `asyncio`.
2. **Отказоустойчивость при сбоях:** При деградации AD или PostgreSQL все потоки пула FastAPI могут зависнуть в ожидании таймаутов, блокируя обработку любых новых HTTP-запросов (риск Denial of Service).
3. **WebSockets и Presence:** Сервис активно использует WebSockets и Redis Pub/Sub, которые нативно работают в Event Loop, но чувствительны к блокировкам основного потока.

---

## 2. Предлагаемое решение (Архитектурный план)

При росте нагрузки до тысяч одновременных пользователей или переходе к распределенному развертыванию реализовать полную асинхронность:

### 2.1 Миграция базы данных (PostgreSQL)
* Заменить синхронный драйвер `psycopg2` на асинхронный `asyncpg`.
* Перевести сессии SQLAlchemy на `AsyncSession` и `create_async_engine`.
* Использовать `await session.execute(...)` и `await session.commit()`.

### 2.2 Миграция LDAP (Active Directory)
* Заменить синхронную библиотеку `ldap3` на асинхронную библиотеку `bonsai` (с нативной поддержкой `asyncio` и libldap).
* Переписать модуль `app.core.ldap` (пул соединений и операции аутентификации/поиска) на `async/await`.

### 2.3 Обновление обработчиков FastAPI
* Перевести эндпоинты в `app.api.endpoints` на `async def`.
* Все операции ввода-вывода (I/O) будут обрабатываться в рамках общего Event Loop без необходимости порождать потоки ОС.
