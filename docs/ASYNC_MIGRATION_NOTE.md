# Планирование перехода на полностью асинхронный стек

**Дата создания**: 2026-07-05
**Контекст**: Выявлено потенциальное "бутылочное горлышко" в архитектуре. Использование синхронных библиотек (`ldap3`, `SQLAlchemy`) внутри асинхронного фреймворка FastAPI при высоких нагрузках может приводить к исчерпанию пула потоков (Threadpool Exhaustion).

В данный момент проблема решена переводом эндпоинтов в `def` (вместо `async def`), что позволяет FastAPI автоматически выполнять их в пуле потоков (`anyio.to_thread`). Этого достаточно для текущих нагрузок.

## Почему в будущем нужен переход?
Если нагрузка на систему возрастет до тысяч одновременных пользователей или потребуется микросервисная масштабируемость:
1. Синхронные потоки потребляют много памяти и ресурсов CPU на переключение контекста.
2. При падении базы данных или LDAP все 40 (по умолчанию) потоков FastAPI могут зависнуть в ожидании таймаута, что полностью заморозит API (Denial of Service).
3. Приложение интенсивно использует WebSockets, которые идеально работают в Event Loop, но плохо уживаются с перегруженным пулом потоков.

## План миграции (Долгосрочное решение)
Когда текущей архитектуры перестанет хватать, необходимо выполнить следующие шаги:

1. **Миграция БД на асинхронность**
   - Заменить `psycopg2` на драйвер `asyncpg`.
   - Обновить сессии SQLAlchemy: использовать `AsyncSession` и `create_async_engine`.
   - Переписать все CRUD-запросы с использованием `await session.execute(...)`.

2. **Миграция LDAP на асинхронность**
   - Заменить синхронную библиотеку `ldap3` на асинхронную библиотеку `bonsai` (которая имеет нативную поддержку `asyncio`).
   - Переписать `app.core.ldap.auth` и пулы соединений для работы через `async/await`.

3. **Обновление эндпоинтов**
   - Вернуть ключевое слово `async def` всем эндпоинтам в `app.api.endpoints`.
   - Теперь Event Loop сможет обрабатывать тысячи логинов и SQL-запросов одновременно без единой блокировки.

Данная заметка создана для разработчиков будущего, чтобы указать правильный вектор развития архитектуры при росте проекта.
